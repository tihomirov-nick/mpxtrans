# MPXTrans

MPXTrans расшифровывает аудио и видео в текст на macOS. В названии MPX означает файлы .mp с любой цифрой на месте X
(.mp3, .mp4 и так далее), а Trans означает транскрибацию. Вы перетаскиваете в маленькое окно файл любого формата,
Whisper распознаёт речь на самом Mac, без интернета, а текст можно поправить, скопировать, сохранить в файл
или отправить через стандартное меню «Поделиться» macOS.

Готовый установщик `MPXTrans-<версия>.dmg` лежит на странице [релизов](https://github.com/tihomirov-nick/mpxtrans/releases/latest).
Нужна macOS 13.3 или новее, подходят Mac с Apple Silicon и Intel. Инструкция для пользователей есть в `docs/Как установить.txt`.

## Возможности

- MPXTrans открывает файлы любых форматов через встроенный ffmpeg: MP3, M4A, AAC, WAV, AIFF, FLAC, OGG, OPUS, WMA, AMR,
  MP4, MOV, MKV, WEBM, AVI, MTS и другие. Файл можно перетащить в окно или на значок в Dock либо открыть через
  «Открыть с помощью».
- Речь распознаёт Whisper на самом Mac (whisper.cpp 1.9.4, на Apple Silicon через Metal). По умолчанию стоит стандартная
  **Whisper Large v3 Turbo**. В меню внизу окна выбирается любая скачанная модель, в том числе дообученные на русской
  речи, и язык: русский по умолчанию, автоопределение или любой из примерно 100 языков Whisper.
- Папка моделей общая с Subtits (`~/Library/Application Support/Subtits/Models`), и модели, скачанные в Subtits,
  сразу доступны здесь, и наоборот. Недостающие скачиваются в окне «Модели распознавания» с проверкой SHA-256
  и докачкой при обрыве связи.
- Текст появляется по мере распознавания. Прогресс и оставшееся время видны в окне и на значке в Dock, и пока идёт
  распознавание, Mac не засыпает.
- Silero VAD пропускает тишину и музыку, так что Whisper не придумывает фразы на паузах. Ещё один фильтр убирает
  типичные «галлюцинации», например «Субтитры сделал DimaTorzok», «[музыка]» и повторяющиеся фразы.
- Результат бывает трёх видов: текст с абзацами по паузам, текст с таймкодами `[01:23]` и субтитры SRT. Текст можно
  править прямо в окне (⌘F ищет по тексту), правки хранятся отдельно для каждого вида.
- Текст можно скопировать (⇧⌘C), сохранить (⌘S) в `.txt` или `.srt` рядом с исходным файлом или отправить через
  «Поделиться» в AirDrop, Сообщения, Почту (с темой письма), Заметки и другие службы macOS.
- В настройках (⌘,) есть подсказка с именами и терминами. Она подставляется в каждое 30-секундное окно Whisper.
- Оформление сделано в стиле Liquid Glass (iOS 27 / macOS 26). Стеклянные капсулы и карточки лежат над мягким цветным
  фоном, иконка сделана в формате Icon Composer, и на macOS 26 система рисует её настоящим стеклом. На macOS 13–15
  вместо стекла используются системные материалы. Есть светлая и тёмная тема, приложение учитывает настройку
  «Уменьшить движение».
- Интерфейс на русском и английском. Русский включается, если он есть среди языков macOS (как в Subtits), в остальных
  случаях английский. Если в «Системных настройках» в разделе «Язык и регион» для приложения выбран свой язык,
  используется он.

## Сборка

Нужны Xcode (Swift 5.10+) и, только для пересборки whisper.cpp, Homebrew `cmake`.

```bash
./scripts/make_dmg.sh            # всё сразу: зависимости → MPXTrans.app → dist/MPXTrans-1.0.0.dmg
VERSION=1.1.0 ./scripts/make_dmg.sh
```

| Скрипт | Что делает |
|---|---|
| `scripts/build_whisper.sh` | собирает whisper.cpp 1.9.4 (Metal + Accelerate) как universal static library в `Vendor/whisper` |
| `scripts/fetch_ffmpeg.sh` | скачивает статический ffmpeg 9.0.2 (arm64 и x86_64), проверяет SHA-256 и склеивает universal-бинарник в `Vendor/ffmpeg` |
| `scripts/fetch_vad.sh` | скачивает модель Silero VAD с проверкой SHA-256 в `Resources/ggml-silero-v6.2.0.bin` |
| `scripts/build_app.sh` | собирает universal-приложение в `build/MPXTrans.app`: ffmpeg в `Contents/Helpers`, иконка из `Resources/AppIcon.icon` через `actool`, переводы, подпись |
| `scripts/make_dmg.sh` | запускает `build_app.sh` и собирает DMG с ярлыком Applications и инструкциями на русском и английском |

Собранный whisper.cpp уже лежит в `Vendor/whisper` (его скопировали из Subtits), поэтому обычная сборка занимает меньше
минуты. ffmpeg весит 154 МБ, а GitHub не принимает файлы больше 100 МБ, и в git его нет. `build_app.sh` при первой
сборке сам скачает его через `scripts/fetch_ffmpeg.sh`, а для `swift build` этот скрипт нужно один раз запустить
вручную. Скрипты сборки сбрасывают `SDKROOT`, потому что SDK из Command Line Tools в окружении может не совпадать
с компилятором Xcode.

Для разработки хватит `swift build`. Распознавание без интерфейса проверяется консольной утилитой:

```bash
swift build --product mpxtrans-cli
.build/debug/mpxtrans-cli запись.m4a                       # текст в stdout, ход распознавания в stderr
.build/debug/mpxtrans-cli видео.mov --format srt --lang auto
.build/debug/mpxtrans-cli запись.m4a --model large-v3-russian-q5_0 --no-vad --greedy --prompt "Сбербанк, Анна"
```

Иконка лежит в `Resources/AppIcon.icon`. Её можно открыть и поправить в Icon Composer, он открывается в Xcode через
меню Open Developer Tool.

## Тексты и перевод

Строки в коде написаны по-русски внутри `L("…")`, они же ключи перевода. Английский перевод лежит
в `scripts/l10n/en.json`. Из него `scripts/l10n/make_strings.py` собирает `Resources/en.lproj/Localizable.strings`
и останавливает сборку, если у какой-то строки нет перевода или не совпадают `%@`.

## Подпись и Gatekeeper

По умолчанию приложение подписывается ad-hoc, и на других Mac его нужно разрешить при первом запуске. Для этого
в «Системных настройках» откройте «Конфиденциальность и безопасность» и нажмите «Всё равно открыть», подробности
есть в `docs/Как установить.txt`. Чтобы предупреждения не было, нужен сертификат **Developer ID Application**
и нотаризация:

```bash
SIGN_IDENTITY="Developer ID Application: Имя (TEAMID)" ./scripts/make_dmg.sh
xcrun notarytool submit dist/MPXTrans-1.0.0.dmg --keychain-profile <профиль> --wait
xcrun stapler staple dist/MPXTrans-1.0.0.dmg
```

## Где что лежит

- В `Sources/TransCore` лежат работа с ffmpeg (`FFmpeg` читает сведения о файле и готовит звук 16 кГц), распознавание
  (`WhisperEngine` с фильтром галлюцинаций), форматы результата (`Transcript`: текст с абзацами, таймкоды, SRT),
  каталог моделей и локализация.
- В `Sources/MPXTrans` лежит интерфейс на SwiftUI: `Transcriber` (состояние окна и задача распознавания), `ModelStore`
  (загрузка моделей), `Views/` (зона перетаскивания, прогресс, результат, окно моделей, настройки, стеклянные элементы
  в `Glass.swift`) и `DebugHooks` (переменные окружения `MPXTRANS_*` для автоматических проверок интерфейса).
- В `Sources/MPXTransCLI` лежит консольная утилита.
- Модели хранятся в `~/Library/Application Support/Subtits/Models/`, это общая папка с Subtits. Настройки лежат
  в `UserDefaults` (`com.mpxtrans.app`). Временные файлы со звуком удаляются сразу после распознавания.
